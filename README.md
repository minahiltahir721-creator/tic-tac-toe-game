# Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**. The game allows users to play either with another player or against an **AI opponent** when another player is not available.

## Features

* 🎮 Two-player mode
* 🤖 Play against AI
* 🏆 Automatic win detection
* 🤝 Draw detection
* 🔄 Restart game option
* 📱 Responsive and user-friendly interface
* ✨ Simple and interactive design

## Game Modes

### 👥 Player vs Player

Play Tic Tac Toe with a friend on the same device.

### 🤖 Player vs AI

If another player is not available, you can play against the built-in AI opponent.

## Technologies Used

* HTML
* CSS
* JavaScript
